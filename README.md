# East African Birds — photo-enabled build

Avibase Eastern Africa checklist: 1,851 species, Clements 2025.
Source: https://avibase.bsc-eoc.org/checklist.jsp?region=AFE

This version adds a real licensed-media retrieval layer using the iNaturalist API. It requests only CC0, CC BY and CC BY-SA photos and displays attribution/licence information.

Important: the bundled database contains the verified subset available from the extracted Avibase page, not a fabricated claim of 1,851 bundled records. The UI and schema are ready for the complete checklist import.

AI photo identification remains a separate trained-model component. It is intentionally not faked with random/speculative results.
